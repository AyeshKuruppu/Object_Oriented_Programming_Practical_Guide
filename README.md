## 📌 About This Project

This repository contains a collection of **Java practical programs** developed to understand and apply **Object-Oriented Programming (OOP)** concepts.

Instead of learning OOP only through theory, this project uses small, focused programs to make concepts easier to understand, implement, and revise.

### 🎯 Main Objectives

- 🧠 Understand the fundamentals of Object-Oriented Programming
- ☕ Improve Java programming skills
- 🧩 Practice classes and objects
- 🔒 Understand encapsulation
- 🏗️ Practice abstraction and inheritance-related concepts
- 🔄 Understand method-based object interaction
- 💻 Develop practical problem-solving skills
- 📚 Build a useful collection of OOP examples for academic revision
